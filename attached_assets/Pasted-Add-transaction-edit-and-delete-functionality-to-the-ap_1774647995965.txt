BACKEND — NEW/UPDATED ROUTES
═══════════════════════════════════════════════

PATCH /api/transactions/:id
Update an existing transaction:
- Accept body: { type, amount_original, currency_code, 
  notes, transacted_at }
- Re-calculate amount_usd using current rate from 
  currencies table:
  amount_usd = amount_original * rate_to_usd
- Update fx_rate_used with the current rate
- Only allow user to edit their OWN transactions:
  Check transaction belongs to user's account before 
  updating. If not: return 403 { error: 'Unauthorized' }
- Return updated transaction object

DELETE /api/transactions/:id (fix existing):
- Soft delete: SET deleted_at = NOW()
- Only allow user to delete their OWN transactions
- Return { success: true, message: 'Transaction deleted' }
