AUTH (fix existing):
- POST /api/auth/register → bcrypt hash password, create user + default account, return {token, user}
- POST /api/auth/login → verify password, return {token, user}
- GET /api/auth/me → return current user (JWT middleware)
- PATCH /api/user → update name, home_currency, notification_frequency

TRANSACTIONS:
- GET /api/transactions?timeframe=day|week|month|year → user's transactions filtered by timeframe, newest first, exclude deleted
- POST /api/transactions → body: {type, amount_original, currency_code, notes, transacted_at}. Look up rate from currencies table, calculate amount_usd = amount_original * rate_to_usd, save and return full transaction
- DELETE /api/transactions/:id → soft delete (set deleted_at = now())
- GET /api/transactions/summary?timeframe=day|week|month|year → return: {total_income_usd, total_expense_usd, net_usd, transaction_count, profit_status: 'profit'|'loss'|'breakeven', income_rate_per_hour, expense_rate_per_hour, insight_message}
  insight_message examples: "You're spending $3.20/hour today" / "You're up $45.00 this week 🎉" / "3-day loss streak — review your expenses"

CURRENCIES:
- GET /api/currencies → return all currencies with current rates
- POST /api/currencies/refresh → fetch from Open Exchange Rates API using EXCHANGE_RATES_API_KEY env var, update rates in DB, return {updated: count}. If API key is placeholder or missing, skip silently and return {updated: 0, note: 'using cached rates'}

ANALYTICS:
- GET /api/analytics/chart?days=7|30 → return [{date, income_usd, expense_usd, net_usd}] grouped by day for that user
- GET /api/analytics/insights → return array of 3 insight objects [{type, message, tone: 'positive'|'neutral'|'warning'}] based on last 30 days

EXPORT:
- GET /api/export/csv → stream CSV of all user transactions as file download
