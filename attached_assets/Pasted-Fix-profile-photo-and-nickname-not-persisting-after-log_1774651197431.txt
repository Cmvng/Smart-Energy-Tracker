2. Auth context / useAuth hook:
On app startup, do NOT just read from localStorage.
Instead:
- Read token from localStorage
- If token exists: immediately call GET /api/auth/me
- Use the fresh database response to populate user state
- Update localStorage with fresh data from server
This ensures avatar_url and nickname are always 
fresh from the database, not stale from localStorage

The flow:
const token = localStorage.getItem('ine_token')
if (token) {
  const res = await fetch('/api/auth/me', {
    headers: { Authorization: `Bearer ${token}` }
  })
  if (res.ok) {
    const data = await res.json()
    setUser(data.user) // fresh from DB
    localStorage.setItem('ine_user', 
      JSON.stringify(data.user)) // update cache
  } else {
    // Token expired - clear and redirect to login
    localStorage.removeItem('ine_token')
    localStorage.removeItem('ine_user')
    navigate('/login')
  }
}

AVATAR SIZE FIX
═══════════════════════════════════════════════
Base64 images can be very large (1-3MB) which 
causes two problems:
1. localStorage has a 5MB limit — large avatars 
   can crash the app
2. Slow page loads

Fix by compressing the image before upload:

In the file input onChange handler, before uploading:
- Create an <img> element and load the file
- Draw it on a <canvas> at max 200×200 pixels
- Export canvas as JPEG at 0.7 quality
- This reduces a 2MB photo to ~20KB
- Upload the compressed version

Code:
const compressImage = (file) => {
  return new Promise((resolve) => {
    const reader = new FileReader()
    reader.onload = (e) => {
      const img = new Image()
      img.onload = () => {
        const canvas = document.createElement('canvas')
        const MAX = 200
        let w = img.width, h = img.height
        if (w > h) {
          if (w > MAX) { h *= MAX/w; w = MAX }
        } else {
          if (h > MAX) { w *= MAX/h; h = MAX }
        }
        canvas.width = w
        canvas.height = h
        canvas.getContext('2d').drawImage(img, 0, 0, w, h)
        canvas.toBlob(resolve, 'image/jpeg', 0.7)
      }
      img.src = e.target.result
    }
    reader.readAsDataURL(file)
  })
}

// In onChange:
const compressed = await compressImage(file)
const formData = new FormData()
formData.append('avatar', compressed, 'avatar.jpg')
// Then POST to /api/user/avatar
