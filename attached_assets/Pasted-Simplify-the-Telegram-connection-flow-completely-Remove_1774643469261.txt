HOW IT WORKS:
When user clicks "Activate Telegram Notifications" in the app Settings:
1. App opens Telegram automatically using this deep link:
   https://t.me/smartinetracker_bot?start=[user_id]
   (where user_id is the logged-in user's UUID from the database)
2. Telegram opens on the user's phone with the bot already loaded
3. User just taps the "START" button that Telegram shows automatically
4. The bot receives /start [user_id] as the message
5. Bot looks up the user_id in the database, saves their telegram chat_id
6. Bot replies: "🎉 You're all connected [name]! 
   I'll send you friendly reminders to track your finances.
   Try /summary to see today's numbers!"
7. Back in the app Settings, the button automatically updates to 
   show "✅ Telegram Connected" after 3 seconds
