  page text,
  created_at timestamptz DEFAULT now()

BACKEND ROUTES
═══════════════════════════════════════════════
All admin routes require JWT + is_admin = true.
If not admin: return 403 { error: 'Unauthorized' }

GET /api/admin/stats:
Return:
{
  total_users: COUNT(*) FROM users,
  new_today: COUNT WHERE created_at >= today,
  new_this_week: COUNT WHERE created_at >= 7 days ago,
  total_transactions: COUNT(*) FROM transactions 
    WHERE deleted_at IS NULL,
  transactions_today: COUNT WHERE created_at >= today,
  active_today: COUNT DISTINCT account_id FROM 
    transactions WHERE created_at >= today,
  users_by_currency: SELECT home_currency, 
    COUNT(*) as count FROM users 
    GROUP BY home_currency ORDER BY count DESC,
  recent_signups: SELECT u.id, u.name, u.email, 
    u.nickname, u.mode, u.home_currency, 
    u.created_at,
    u.telegram_chat_id IS NOT NULL as telegram_connected,
    COUNT(t.id) as transaction_count
    FROM users u
    LEFT JOIN accounts a ON a.user_id = u.id
    LEFT JOIN transactions t ON t.account_id = a.id 
      AND t.deleted_at IS NULL
    GROUP BY u.id
    ORDER BY u.created_at DESC
    LIMIT 20
}

GET /api/admin/users:
Return all users with transaction counts.
Support ?search=email_or_name query param.

GET /api/admin/feedback:
Return all feedback ordered by created_at DESC.
Include user name and email with each feedback row.

POST /api/feedback:
Accept { rating, message, page }
Save to feedback table for current user.
Return { success: true }

GET /api/auth/me update:
Add is_admin field to the response.
