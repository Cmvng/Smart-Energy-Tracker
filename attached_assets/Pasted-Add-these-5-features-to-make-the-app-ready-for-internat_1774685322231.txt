2. PASSWORD RESET
═══════════════════════════════════════════════
Add forgot password flow:

DATABASE:
CREATE TABLE IF NOT EXISTS password_reset_tokens (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid REFERENCES users(id),
  token text UNIQUE,
  expires_at timestamptz,
  used boolean DEFAULT false,
  created_at timestamptz DEFAULT now()
);

BACKEND:
POST /api/auth/forgot-password:
- Accept { email }
- Find user by email
- If not found: return same success message 
  (security — don't reveal if email exists)
- Generate random 6-digit code (not a link — 
  easier for mobile users)
- Store in password_reset_tokens with 
  expires_at = now + 15 minutes
- Send email using nodemailer or log to console
  if no email service configured:
  Subject: "Your Smart i-n-E password reset code"
  Body: "Your reset code is: [CODE]
  This code expires in 15 minutes.
  If you didn't request this, ignore this email."
- Return { success: true, message: 'Reset code sent' }

POST /api/auth/reset-password:
- Accept { email, code, newPassword }
- Find valid token: not expired, not used, 
  matches email
- If invalid: return 400 { error: 'Invalid or expired code' }
- Hash new password with bcrypt
- Update users.password_hash
- Mark token as used
- Return { success: true }

FRONTEND:
On login page, "Forgot password?" link opens 
a 3-step flow:

Step 1 — Enter email:
Input for email address
"Send Reset Code" button
→ POST /api/auth/forgot-password

Step 2 — Enter code:
"Enter the 6-digit code sent to [email]"
6 individual digit input boxes (like OTP style)
OR single input field
"Verify Code" button
Resend code link (after 60 seconds)

Step 3 — New password:
"New password" input
"Confirm password" input
"Reset Password" button
→ POST /api/auth/reset-password
On success: redirect to login with toast
"✅ Password reset! Please log in."

Show this as a modal or separate small page.
Back button to return to login at each step.
